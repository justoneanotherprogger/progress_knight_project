# AGENTS.md

Инструкции для ИИ-агентов, работающих в этом репозитории. Загружаются автоматически при сканировании проекта.

## Проект

Мод игры Progress Knight Quest (оригинал — https://indomit.github.io/progress_knight_2/): баланс, названия и контент — авторское видение владельца репозитория, не апстрима. Чистый JS без сборщика на фронте + Python-сборка контента.

Пайплайн сборки (`build.py`, Jinja2):

- `locales/<lang>/*.yaml` и `content/*.json` → `dist/js/translations.js` и `dist/js/*_data.js`
- `templates/*.html` и `templates/partials/*` → корневой `index.html`

Все три артефакта — генераты: в git не хранятся (`.gitignore`), деплой-пайплайн
собирает их сам. Сгенерированные файлы лежат в `dist/`, кроме `index.html` — его
нельзя вынести, деплой отдаёт его как `/`. Локальная проверка после изменения JSON
или шаблонов — `python build.py`. Балансные правки — в исходниках (`js/*.js`,
`locales/`, `content/`, `templates/`), не в генератах.

## Структура

- `js/` — игровой код; `vendor/` — вендорские бандлы (mathjs, break_infinity, HackTimer), не редактируются
- `dist/` — сгенерированные `*_data.js` и `translations.js`, редактировать нельзя
- `templates/`, `locales/`, `content/` — источники интерфейса, текстов и баланса
- `build.py` — генерация переводов и HTML из источников
- `scripts/` — служебные скрипты проверок

## Сдерживание роста файлов

Рэтчет размеров (`scripts/check_file_size.py`) гоняет **только CI** — на каждый push/PR
(деплой в GitHub Pages — отдельным workflow). Локально перед коммитом его **не прогоняем**:
ручной прогон провоцирует резать файл на ходу — «блин, проверка не проходит, сейчас
тут отрежу» — вместо осознанного решения.

Файл упёрся в лимит — это отдельная задача: разбираешь, что именно разрослось, и режешь
по структуре. Тогда `scripts/check_file_size.py` и зовётся — как инструмент разбора при
разгрузке.

Исходники (`.js`, `.html`, `.css`, `.yaml`, `.py`) — до **1000 строк**. Переросшие
исторически файлы запинены в `scripts/source-file-size-baseline.json` и могут только
уменьшаться: любой рост запиненного файла отклоняется; похудевший требует понижения
записи там же; дорос до лимита — запись удаляется.

Лимит, расширения и исключённые каталоги настраиваются в том же JSON — код чекера менять не нужно.

## Линт и форматирование

Biome (`biome.json`, `@biomejs/biome` в devDependencies). `npm run lint` — проверка,
`npm run fix` — авто-фиксы (`--unsafe` там, где нужно). Линт гоняет локальный
`hooks/pre-commit` перед коммитом, рядом с рэтчетом размеров. Хук включается один раз
на клон: `git config core.hooksPath hooks`.

Сгенерированные файлы (`translations.js`, `*_data.js`, `index.html`) в проверку не
попадают — Biome уважает `.gitignore`; `vendor/` исключён отдельно.

`noUnusedVariables` выключен намеренно. Скрипты делят глобальную область, правило не
видит использования из других файлов, а его небезопасный авто-фикс переименовывает живые
символы с префиксом `_` (`removeSpaces` → `_removeSpaces`) и ломает игру с
`ReferenceError`. Проверено: до подключения линтера в проекте не было ни одного
намеренно подчёркнутого объявления, все `_` пришли из этого фикса. Снимется переводом
на ES-модули, где межфайловые связи станут явными.
